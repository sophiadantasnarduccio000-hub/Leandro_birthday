### 📱 Ativar GitHub Pages pelo Celular:

1. **Abra o navegador e vá para:**
   ```
   https://github.com/sophiadantasnarduccio000-hub/Leandro_birthday/settings/pages
   ```

2. **Na página que abrir:**
   - Procure por "Source" ou "Fonte"
   - Selecione a branch: **main**
   - Selecione a pasta: **/ (root)**
   - Clique em **Save** (Salvar)

3. **Pronto!** Seu site estará disponível em 2-5 minutos
